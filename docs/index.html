安装不会自动开始监测。安装包或 Skill 不会自行运行或建立定时任务。需要监测时，在 Codex 明确说“启用额度监测”或“每3小时监测”；只有确认真实账号帖子可读、静默基线建立，并验证自动化配置后，才算启用。

让提醒保持清楚

程序从静默基线开始，之后按帖子和阶段去重。每一条提醒留在待确认列表，直到你亲自执行确认。

分开公告与完成

先对重置公告提醒一次；出现明确的完成措辞后，再对完成状态提醒一次。

本地状态

SQLite 保存去重与待确认状态。Windows 可选择显示本地窗口收据。

时间不猜测

时间分类包含明确、估计、未知。没有依据时显示未知，不把推测写成事实。

几步开始

按需安装

Source ZIP 用于运行 CLI；Skill ZIP 只教 Codex 如何协助设置。需要两者时分别安装。

新回合调用 Skill

安装 Skill 后新开 Codex 回合，调用 $codex-quota-watch。未识别时重启 Codex。

明确请求监测

说“启用额度监测”或“每3小时监测”。需要真实、可刷新的来源和可用登录。

验证后安排

成功读取后静默建立基线，再配置当前聊天三小时检查；失败时不会声称已启用。

默认 Windows Skill 路径：$HOME\.codex\skills\codex-quota-watch\SKILL.md；自定义 CODEX_HOME 时为 $env:CODEX_HOME\skills\codex-quota-watch\SKILL.md。Skill ZIP 内部只有单层 codex-quota-watch/SKILL.md，直接解压到 skills 根目录即可。完整解压命令见安装指南。

python -m pip install .
codex-quota-watch --state-dir .\state init
codex-quota-watch --state-dir .\state poll --input .\examples\baseline.json --dry-run
codex-quota-watch --state-dir .\state status
codex-quota-watch --state-dir .\state ack <提醒ID>

完整安装、JSON 格式与数据源示例见安装指南 →

适用范围与限制

项目内的帖子文件是合成样例，不是当前公告，也不包含真实用户数据。包本身不安装 X/Twitter 登录或凭证。

来源需自行配置

allowlist 目前为 thsottiaux。采集命令和账号状态由运行者维护。

文本规则有边界

分类偏保守，但讽刺、引用、否定和复杂语境仍可能带来误判。

不切换模型

没有可验证的 Codex 宿主切换接口，因此不会自动换模型。宠物或动画提示属于尽力而为，不保证送达。
